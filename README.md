# PSS Makeup Studio

Marketing site for PSS Makeup Studio: services, academy, portfolio, and booking (Vite + React + TypeScript + Tailwind).

Lockfiles: this repo uses **`package-lock.json`** with npm. If you use Bun, run `bun install` to generate a fresh `bun.lock`.

## Scripts

- `npm run dev` — start dev server (port 8080)
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run test` — Vitest unit tests

## Playwright

End-to-end tests can live under `e2e/`. Config uses the same dev server URL as Vite (`http://localhost:8080`).
